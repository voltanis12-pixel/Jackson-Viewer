# Jackson Viewer Support

## Support Scope

Jackson Viewer is an independently maintained third-party viewer for Second Life.

This software is not provided or supported by Linden Lab, the makers of Second Life.

For problems specific to Jackson Viewer, use the GitHub Issues section of this repository.

## Appropriate Jackson Viewer Issues

Examples include:

- Jackson Viewer installation failures
- Jackson-specific interface problems
- Jackson inventory organization features
- Jackson branding or visual problems
- Viewer crashes or regressions reproducible specifically in Jackson Viewer
- Problems introduced by Jackson Viewer modifications

When reporting a problem, include the Jackson Viewer version shown under Help > About Jackson Viewer and clear steps to reproduce the issue.

## Linden Lab and Second Life Issues

Problems involving the Second Life service itself should be directed to Linden Lab when appropriate. Examples include account access, billing, grid-wide outages, account enforcement, and other Linden Lab-controlled services.

Do not represent Jackson Viewer as an official Linden Lab product when requesting support.

Windows 64-bit
Channel: Jackson Release

## Security

The RC2 Windows installer is currently unsigned. Windows may display an Unknown Publisher or Microsoft Defender SmartScreen warning.

Always download Jackson Viewer from the official Jackson Viewer GitHub repository and verify the SHA-256 checksum published with the release.
