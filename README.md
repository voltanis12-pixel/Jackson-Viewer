# Jackson Viewer

Jackson Viewer is a third-party viewer for Second Life, built from the open-source Second Life Viewer codebase.

The project combines the standard Second Life viewer foundation with a custom Southern Gothic interface, Jackson-themed visual design, inventory organization enhancements, and additional viewer-side improvements.
